# Household Access System

Household Access System is a planned Go backend for modeling household membership, profile ownership, and access permissions.

## Purpose

This repository will support a staged migration from a legacy profile schema toward explicit login, household, profile, and access relationships.

## Planned Stack

- Go backend
- PostgreSQL 16
- SQL migrations
- Docker Compose for local infrastructure

## Scaffold Status

The repository currently contains only the initial project structure. Domain models, migrations, API routes, access-control logic, and database integrations have not been implemented yet.
